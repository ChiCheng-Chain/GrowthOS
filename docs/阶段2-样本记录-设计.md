## 状态设计(SampleViewModel)

```kotlin
data class SampleEditUiState(
    val domains: List<Domain> = emptyList(),          // 可见领域(chips)
    val errorTypes: List<ErrorType> = emptyList(),    // 所有已有错误类型(内联选择)
    val form: SampleForm = SampleForm(),              // 表单
    val isEditing: Boolean = false,                   // true=编辑已有,false=新建
    val isNewErrorTypeDialogOpen: Boolean = false     // 新建错误类型对话框开关
)

data class SampleForm(
    val domainId: Long? = null,
    val result: String = "",
    val description: String = "",
    val errorTypeId: Long? = null,
    val attribution: Attribution? = null,
    val emotionIntensity: Int? = null,
    val review: String = ""
) {
    val isValid: Boolean get() =
        domainId != null &&
        result.isNotBlank() &&
        description.isNotBlank() &&
        errorTypeId != null &&
        attribution != null &&
        review.isNotBlank()
}
```

- `domains`:`DomainRepository.observeVisible()`。
- `errorTypes`:`ErrorTypeRepository.observeAll()`(全局,不分领域)。
- `form`:`MutableStateFlow<SampleForm>`,逐字段更新函数(`updateResult` / `updateAttribution` 等)。
- `isEditing` + 预填:初始化时若 `sampleId != null`,从 `SampleRepository.getById(sampleId)` 预填 `form` 且 `isEditing = true`。
- 新建态领域默认:`domainId` 初始从 `SelectedDomainStore.flow` 取当前选中(阶段 1 持久值),`combine` 进 `uiState`。
- `save()`:`isValid` 时——新建 → `insert(Sample(..., recordedAt = TimeUtil.nowMillis(), ...))`;编辑 → `update(existing.copy(保留 recordedAt, 其余字段用 form))`;完成后发"保存完成"事件驱动 `popBackStack`。
- `delete()`:`delete(existing)`;完成发事件驱动返回。
- `createErrorType(name)`:`errorTypeRepository.getOrCreate(name.trim())` → 设 `form.errorTypeId`(立即选中);`observeAll()` 自动推送新类型进列表;关对话框。
- `Factory` 注入:`sampleRepository` / `errorTypeRepository` / `domainRepository` / `selectedDomainStore` / `sampleId: Long?`。

今日列表态(RecordScreen 用,可独立小 ViewModel 或复用同一个):

```kotlin
data class TodayListUiState(
    val samples: List<Sample> = emptyList()   // observeToday(),已按 recordedAt DESC

```

## 导航接线

- NavHost 加路由 `sample_edit?sampleId={sampleId}`(`sampleId` 可选,默认 `-1` 表示新建)。
- RecordScreen 快速记录 `onClick` → `navigate("sample_edit")`(新建)。
- RecordScreen 列表项点击 → `navigate("sample_edit?sampleId=$id")`(编辑)。
- SampleEditScreen 顶部返回箭头 + 保存 / 删除后 `popBackStack()`。
- 参数解析:`sampleId > 0` 为编辑,否则新建。

## 数据流

```
新建态默认领域:
  SelectedDomainStore.flow → SampleViewModel → form.domainId(初始)

今日列表:
  SampleRepository.observeToday() → TodayListUiState → RecordScreen 渲染

编辑预填:
  SampleRepository.getById(sampleId) → form 预填 + isEditing=true

保存:
  form(isValid) → SampleRepository.insert/update → popBackStack
  → observeToday() Flow 自动推送,今日列表刷新

错误类型新建并立即选中:
  ErrorTypeRepository.getOrCreate(name) → form.errorTypeId
  → ErrorTypeRepository.observeAll() Flow 自动推送,新类型出现在选择列表

删除:
  SampleRepository.delete(sample) → popBackStack → 今日列表刷新
```

## 关键决策

### D1 详情即编辑,不开只读详情页

R-002 要求"查看"与"修改"。本阶段合一:点列表项进 SampleEdit 编辑态,直接可改。理由:自用场景查看多是为改或回想,只读态多一次操作;合一降摩擦,对齐 N-001。代价:无纯浏览态,但 MVP 自用足够。可演进:若后续要分享 / 纯展示,再加只读态。

### D2 SampleEdit 用 NavHost 路由,非 BottomSheet

8 字段 + 键盘需完整垂直空间,BottomSheet 装不下且键盘顶得难受。路由有独立返回栈,返回键自然回列表。对齐 [技术方案 §4.1](技术方案设计.md) 导航图(SampleEdit 为子页面)。

### D3 领域选择用 chips,非 dropdown

自用领域一般 3~6 个,chips(`FlowRow`)一眼可见、一点即中,比 dropdown 少一次展开;默认选中当前领域,零操作即可继续记录当前领域。复用阶段 1 `DomainChip` 样式,视觉一致。可演进:领域超 8 个再考虑 dropdown 或搜索。

### D4 错误类型新建走 getOrCreate,重名不阻断,立即选中

R-004 跨领域复用核心。[ErrorTypeRepository.getOrCreate](../android/app/src/main/java/com/growthos/app/data/repository/ErrorTypeRepository.kt) 已封装踩坑 P6(重名 `INSERT OR IGNORE` 返回 -1 会污染外键)。录入页拿 `getOrCreate` 返回的 id 设 `form.errorTypeId`,`observeAll()` 自动推送新类型出现在列表。重名不阻断 = 同名直接复用已有,避免重复创建污染统计。

### D5 删除入口在编辑页底部 + 确认,列表不长按

样本删除放编辑页底部"删除"按钮 + `AlertDialog` 确认(R-014)。列表不长按删除:防误触,且列表长按语义阶段 1 已用于领域编辑,混用易混。样本无下游引用(原则关联阶段 6 才做),确认即删,不需引用检查(区别于删领域 / 错误类型)。

### D6 情绪强度可选,默认不填,5 档点选器

R-006 可选。默认 null 不阻塞记录(对齐 N-001 低摩擦,大多时候不填)。UI 用 5 档点选保证 1~5 合法,不靠键盘。DB 存 null 或 1~5。

### D7 recordedAt 新建取 now,编辑不改

新建 = `TimeUtil.nowMillis()`;编辑保留原值。理由:保持简单,改时间非 MVP 核心。可演进:若实际需要补录 / 改时间,编辑页加时间选择器。

### D8 SampleStub 部分清理

本阶段清 [RecordScreen](../android/app/src/main/java/com/growthos/app/ui/record/RecordScreen.kt) 对 `SampleStub.examples` 的引用(接 `observeToday`)。[DomainScreen](../android/app/src/main/java/com/growthos/app/ui/domain_view/DomainScreen.kt) 的 `errorDistribution` 占位留阶段 3(领域页四区块接真数据时一并清)。[SampleStub](../android/app/src/main/java/com/growthos/app/domain/model/SampleStub.kt) 文件本阶段不删,阶段 3 清完再删。
