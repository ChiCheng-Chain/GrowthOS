# GrowthOS 阶段 2:样本记录闭环 需求文档

## 文档定位

本文件是二期阶段 2(样本记录闭环)的细化需求。需求基线以 [MVP 需求文档](MVP需求文档.md) R-002 ~ R-007、R-014、N-001 为准,本文件不重复原文措辞,只把它落地到可实施的交互、字段与边界。技术实现见配套《阶段2-样本记录-设计》。前置依赖:阶段 0 数据层、阶段 1 领域管理已落地。

阶段 2 是 MVP 心脏——做完"记一条 → 今日列表出现",闭环第 2~4 环全压在这一页。字段顺序与默认值的设计直接决定 N-001(30 秒~2 分钟)能否达成。

## 范围

做:

- 在任意可见领域下录入一条样本(7 个字段,≤8 满足验收标准 10)
- 查看样本详情(详情即编辑态,无只读页)
- 修改已保存样本
- 删除误录样本(确认对话框,R-014)
- 错误类型内联选择 + 新建并立即选中(跨领域复用,R-004)
- 归因四选一 chips(R-005)
- 情绪强度可选(1~5,R-006)
- 今日样本列表接真数据,替换 [SampleStub](../android/app/src/main/java/com/growthos/app/domain/model/SampleStub.kt) 占位
- 快速记录入口 → 录入页
- 新建样本默认选中当前领域

不做(留后续):

- 列表按错误类型 / 归因筛选(R-007 should 级)→ 阶段 3
- 领域页四区块接真数据 → 阶段 3
- 周复盘 → 阶段 4
- 改记录时间 → 可演进(见 D7)
- 样本附件 / 图片 → MVP 外

## 用户场景

1. **快速记录**:今日记录页点"快速记录",进录入页,领域已默认选中当前,填结果 → 错误类型 → 归因 → 复盘,30 秒~2 分钟保存,回列表见新条。
2. **新建错误类型**:录样本时错误类型列表没有合适的,点"+ 新建",输入名(如"接杀前没回位"),立即选中,继续录。下次录同类直接复用,不必再建。
3. **跨领域复用**:错误类型全局共享。在编程领域录的"边界条件遗漏",切到羽毛球领域录样本时,列表里直接可选。
4. **改样本**:今日列表点一条,进编辑态,改字段保存,列表更新。
5. **删样本**:编辑页底部"删除",确认后删,列表消失。
6. **情绪可选**:大多时候不填情绪;上头那次才标个 4 或 5。
7. **今日空状态**:今天还没记,列表空,提示去快速记录。

## 功能点

### F1 快速记录入口

- 位置:[RecordScreen](../android/app/src/main/java/com/growthos/app/ui/record/RecordScreen.kt) 横通栏(墨底白字,已就位)。
- 行为:点击 → 进入 SampleEdit(新建态)。
- 领域预填:新建态默认选中当前选中领域([SelectedDomainStore](../android/app/src/main/java/com/growthos/app/data/local/SelectedDomainStore.kt) 持久值);无可见领域时,录入页引导先建领域(对接阶段 1 空状态)。

### F2 录入页(SampleEdit)

- 形态:独立路由页(NavHost),非 BottomSheet。理由见设计 D2。
- 新建 vs 编辑:路由参数 `sampleId`,null / 未传 = 新建,非 null = 编辑(预填)。
- 字段顺序(记录摩擦从低到高,对齐 [技术方案 §4.2](技术方案设计.md)):
  1. 领域(chips,默认选中当前,可见领域)
  2. 结果(单行文本,必填)
  3. 一句话描述(多行文本,必填)
  4. 错误类型(内联选择,优先展示已有,可新建)
  5. 归因(四选一 chips,必填)
  6. 情绪强度(1~5,可选,默认不填)
  7. 一句话复盘(多行文本,必填)
- 必填:领域、结果、描述、错误类型、归因、复盘。情绪可选。
- 校验:必填 trim 后非空;情绪若填则 1~5。必填未满足时保存钮 disabled。
- 保存:新建 → insert(`recordedAt = now`);编辑 → update(保留原 `recordedAt`)。保存后返回今日列表。
- 字段数 7(≤ 8,满足验收标准 10)。

### F3 错误类型内联选择 + 新建

- 展示:所有已有错误类型(全局,不分领域,跨领域复用 R-004),按创建时间升序。
- 选择:点选即选中,单选。
- 新建:列表末尾"+ 新建"chip → 底部对话框输入名 → 保存。重名不阻断(走 `getOrCreate`,同名直接复用已有),立即选中。
- 这是闭环第 3 环的产品价值(R-004),不能省。理由见设计 D4。

### F4 归因四选一

- 固定四值 chips:[Attribution](../android/app/src/main/java/com/growthos/app/domain/model/Attribution.kt) 枚举固化——可控错误 / 不可控波动 / 对手或外部强 / 环境问题。
- 单选,必填。
- "可控错误"用琥珀强调色标(对齐 [Ledger.kt](../android/app/src/main/java/com/growthos/app/ui/components/Ledger.kt) 的 `NextActionBlock`,即 `colorScheme.primary`)。

### F5 情绪强度(可选)

- 1~5,5 档点选,不靠键盘输入(保证合法值)。
- 默认不填(可空)。填了才入 1~5。
- 可清空:选中某档再点同一档取消,回到未填。

### F6 今日样本列表

- 位置:[RecordScreen](../android/app/src/main/java/com/growthos/app/ui/record/RecordScreen.kt) 快速记录入口下方。
- 数据:`SampleRepository.observeToday()`,替换 `SampleStub.examples`。
- 列表项:领域 · 时间 / 结果 / 错误类型 · 归因 / 复盘(`NextActionBlock`)。点击进编辑页。
- 倒序:按 `recordedAt DESC`(DAO 已排)。
- 空状态:今日无样本,提示"今天还没记,去快速记录一条"。

### F7 查看详情 / 编辑 / 删除

- 详情即编辑:点列表项 → SampleEdit(编辑态,预填所有字段),直接可改,无只读态。理由见设计 D1。
- 删除:编辑页底部"删除"按钮 → 确认 `AlertDialog` → 确认即删。样本无下游引用,不需引用检查(区别于删领域 / 错误类型)。删除后返回列表。

## 字段与校验

| 字段 | 类型 | 必填 | 校验 |
|---|---|---|---|
| domainId | Long | 是 | 从可见领域选 |
| recordedAt | Long(epoch millis) | 系统 | 新建 = now,编辑不改 |
| result | String | 是 | trim 后非空 |
| description | String | 是 | trim 后非空 |
| errorTypeId | Long | 是 | 从已有选或新建 |
| attribution | Enum | 是 | 四选一 |
| emotionIntensity | Int? | 否 | null 或 1~5 |
| review | String | 是 | trim 后非空 |

## 边界与约束

- **无可见领域时**:录入页引导先建领域(对接阶段 1 空状态)。新建领域后回录入页,领域已就位。
- **错误类型重名**:`getOrCreate` 复用已有,不报错、不阻断(R-004 跨领域复用)。
- **删除样本**:无下游引用(原则可选关联样本,但阶段 6 才做,本阶段删样本不检查引用)。确认即删。
- **recordedAt**:新建取 `now`,编辑保留原值,本阶段不改时间。
- **并发**:自用单设备,不考虑。

## 验收标准

对齐 [MVP 需求文档](MVP需求文档.md) 验收标准 2 / 3 / 4 / 10。

1. 任意可见领域下能录样本,保存后今日列表出现该条。
2. 能新建错误类型并立即选中;下次录同类可直接复用,不必重建。
3. 错误类型跨领域复用:在 A 领域建的错误类型,在 B 领域录入时可选。
4. 能为样本标记归因类型(四选一)。
5. 能查看(进编辑态)、修改、删除样本;删除有确认。
6. 一次记录不超过 8 字段(实际 7)。
