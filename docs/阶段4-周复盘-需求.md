# GrowthOS 阶段 4:周复盘 需求文档

## 文档定位

本文件是二期阶段 4(周复盘)的细化需求。需求基线以 [MVP 需求文档](MVP需求文档.md) R-009 为准,本文件不重复原文措辞,只把它落地到可实施的交互与边界。技术实现见配套《阶段4-周复盘-设计》。前置依赖:阶段 0~3 已落地。

阶段 4 是闭环第 5 步的全局维度——把 [WeeklyScreen](../android/app/src/main/java/com/growthos/app/ui/weekly/WeeklyScreen.kt) 五项从 [SampleStub](../android/app/src/main/java/com/growthos/app/domain/model/SampleStub.kt) 占位换成真实聚合数据,并补时间范围选择器与跨/单领域切换。这阶段仍是"看数据",无新录入入口。

## 范围

做:

- 周复盘页五项接真聚合数据(替换占位):
  - 本周样本数(最近 7 天)
  - 高频错误前三(最近 7 天)
  - 可控错误占比(最近 7 天)
  - 情绪强度最高的样本(最近 7 天)
  - 建议关注的一个高频可控错误(高频 + 可控归因交叉)
- 时间范围选择器:最近 7 天(默认)/ 最近 N 天
- 跨领域(全局)与单领域切换(R-009 should)
- 清理 [WeeklyScreen](../android/app/src/main/java/com/growthos/app/ui/weekly/WeeklyScreen.kt) 对 SampleStub 的引用;清完后删 [SampleStub.kt](../android/app/src/main/java/com/growthos/app/domain/model/SampleStub.kt) 文件(阶段 3 已清 DomainScreen 引用,本阶段清完 WeeklyScreen 后无残留)

不做(留后续):

- 训练前后效果对比 → 阶段 5
- 原则录入 / 列表 → 阶段 6
- 导出 → 阶段 7
- 自定义任意时间区间(非"最近 N 天"的任意起止)→ MVP 外

## 用户场景

1. **看本周全貌**:进复盘页,默认看最近 7 天全部领域——样本数、高频错误前三、可控占比、情绪最高那条、建议关注哪个高频可控错误。一页看懂这周犯了什么、哪些可控、该练什么。
2. **缩到单领域**:切到"编程",五项只算编程领域的最近 7 天,看这个领域本周表现。
3. **拉长时间**:觉得 7 天样本太少,切"最近 30 天",五项重算。
4. **顺建议去训练**:看到"建议关注:边界条件遗漏(可控,本周 4 次)",心里有数该建训练项——但本阶段不建(留阶段 5),只展示建议。
5. **空周**:这周还没记样本,五项显示空状态引导去记录。

## 功能点

### F1 本周样本数

- 数据:最近 7 天样本 count(按时间窗口,跨或单领域)。
- 展示:[LedgerMetric](../android/app/src/main/java/com/growthos/app/ui/components/Ledger.kt) 大数字 + "本周样本"标签。
- 空状态:0 条 → 数字 0,不阻断其余区块。

### F2 高频错误前三

- 数据:`SampleRepository.observeTopErrorTypesLastNDays(n, domainId, limit=3)`(阶段 0 已备),按频次倒序取前三。
- 展示:序号 + 错误类型名 + 次数,复用现 WeeklyScreen 的前三行样式。
- 空状态:无样本 → "还没有样本"。

### F3 可控错误占比

- 数据:`SampleRepository.observeControllableRatioLastNDays(n, domainId)`(阶段 0 已备),分母 total / 分子 controllable。
- 展示:`LedgerMetric`(accent 琥珀色)百分比 = controllable/total。total=0 时显示 "—"。
- 空状态:无样本 → "—"。

### F4 情绪强度最高

- 数据:`SampleRepository.observeHighestEmotionLastNDays(n, domainId)`(阶段 0 已备),返回有情绪强度的最高一条;全 null 返回 null。
- 展示:错误类型名 + 情绪强度(如"压力下急躁(情绪 4/5)")。复用现 WeeklyScreen 样式。
- 空状态:无样本或全无情绪 → "本周无情绪记录"。

### F5 建议关注的高频可控错误

- 数据:最近 N 天内,在可控归因样本中频次最高的错误类型(高频 + 可控交叉)。无则 null。
- 展示:[NextActionBlock](../android/app/src/main/java/com/growthos/app/ui/components/Ledger.kt)(琥珀强调),文案如"「边界条件遗漏」本周可控出现 4 次,建议创建专项训练项"。
- 空状态:无可控错误 → "本周无可控错误,继续保持"。
- 这是闭环第 5 步到第 6 步的衔接(建议 → 建训练项),但本阶段只展示建议,建训练项留阶段 5。

### F6 时间范围选择器

- 选项:最近 7 天(默认)/ 最近 14 天 / 最近 30 天。
- 形态:顶部 chips 单选,选中即切换,五项重算。
- 不做任意起止自定义(MVP 外)。

### F7 跨领域 / 单领域切换

- 选项:全部领域(默认)/ 某个可见领域。
- 形态:顶部 chips(全部 + 各可见领域),单选。与 F6 时间选择器并列。
- 单领域时五项只算该领域;全部领域时 domainId=0(全局)。

## 边界与约束

- **时间窗口**:基于本地时区,最近 N 天 = [startOfToday − (N−1) 天, startOfNextDay)(含今天),对齐 [TimeUtil.lastNDaysRange](../android/app/src/main/java/com/growthos/app/util/TimeUtil.kt)。
- **全局 vs 单领域**:全部领域用 domainId=0(DAO 已支持);单领域用 selectedDomainId 或用户在复盘页选的领域 id。
- **情绪全 null**:F4 返回 null,UI 显示空提示,不报错(对齐踩坑 P7)。
- **可控占比分母 0**:F3 显示 "—",不做除零。
- **建议关注无可控错误**:F5 返回 null,显示正面文案。

## 验收标准

对齐 [MVP 需求文档](MVP需求文档.md) 验收标准 5(查看最近 7 天高频错误前三)。

1. 周复盘页五项展示真实聚合数据(非 SampleStub 占位)。
2. 默认最近 7 天全部领域,能看到高频错误前三。
3. 能切换单领域,五项只算该领域。
4. 能切换时间范围(7/14/30 天),五项重算。
5. 建议关注区块在有可控高频错误时给出建议,无时显示正面文案。
6. 删 [SampleStub.kt](../android/app/src/main/java/com/growthos/app/domain/model/SampleStub.kt)(清完 WeeklyScreen 引用后无残留)。
