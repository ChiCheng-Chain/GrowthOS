# GrowthOS 阶段 7:导出与安全收尾 需求文档

## 文档定位

本文件是二期阶段 7(导出与安全收尾)的细化需求。需求基线以 [MVP 需求文档](MVP需求文档.md) R-013 / R-014 为准,本文件不重复原文措辞,只把它落地到可实施的交互与边界。技术实现见配套《阶段7-导出与安全收尾-设计》。前置依赖:阶段 0~6 已落地,MVP 闭环八步已跑通。

阶段 7 是 MVP 最后一个开发阶段——把数据导出成可迁移的 JSON(R-013),并把 R-014 的删除安全补齐(错误类型删除 + 引用检查)。做完验收标准 9 也达成,代码层面 MVP 完工。

**关键:阶段 7 实际比二期开发计划写的轻。** R-014 的删除安全大部分已在阶段 1~6 落地:样本删除(阶段 2)、原则删除(阶段 6)已有确认对话框,训练项只结束不删(阶段 5),领域只隐藏不物理删除(阶段 1)。唯一缺口是错误类型没有删除入口。R-013 只做导出(导入可选,MVP 不做)。

## 范围

做:

- 导出数据(R-013):五张表(domains / errorTypes / samples / trainings / principles)+ meta(版本号 / 导出时间)序列化为 JSON,走系统存储访问框架(SAF)保存到用户选定位置。
- 设置页:周复盘页顶部入口,含「导出数据」。
- 错误类型删除(R-014):长按错误类型 chip → 引用检查 → 被引用则拦截提示,未引用则确认删除。

不做(留后续):

- 导入(R-013 未要求,技术方案 §7 明确可选)
- AI 自动复盘 / 生成建议 → MVP 外(N-006)
- 领域物理删除(阶段 1 决定只隐藏)
- 最近删除 / 回收站 → MVP 外(技术方案 §8)
- 设置页其他项(关于 / 主题切换 / dynamicColor 开关)→ 后续

## 用户场景

1. **导出备份**:想换设备或备份数据 → 周复盘页顶部点「设置」→ 点「导出数据」→ 系统弹出文件保存选择器 → 选位置命名保存 → 得到一个 JSON 文件,包含全部领域/样本/错误类型/训练项/原则。
2. **删错误类型被拦截**:录样本时长按某个错误类型 chip 想删 → 系统提示「3 条样本 / 1 个训练项在用,无法删除」→ 知道这个错误类型还在被引用,不删。
3. **删错误类型确认**:某个错误类型早期建了没用过,长按 chip → 弹确认「删除这个错误类型?」→ 确认删除,chip 消失。
4. **导出失败**:导出时用户取消保存选择器,或写入失败 → 提示「导出未完成」,不崩。

## 功能点

### F1 设置页

- 入口:周复盘页顶部「设置」入口(与「训练项」「原则库」并列,阶段 5/6 已建)。
- 内容:列表式,首项「导出数据」。后续可扩展(关于 / 主题,本阶段不做)。
- 顶部返回。

### F2 导出数据(R-013)

- 触发:设置页点「导出数据」。
- 数据:五张表全量 + meta(版本号 / 导出时间),序列化为 JSON。
- 保存:走系统存储访问框架 `CREATE_DOCUMENT`,弹出系统文件保存选择器,用户选位置 + 命名 → 写入。无需申请存储权限(对齐技术方案 §7 + Android 13+ scoped storage)。
- 结果:成功提示「已导出」;取消或失败提示「导出未完成」,不崩。
- 导入不做(D2)。

### F3 错误类型删除(R-014)

- 触发:录样本页错误类型 chip 长按(阶段 1 领域 chip 长按进编辑的范式)。
- 引用检查:查 `ErrorTypeRepository.referenceCount(id)`(= 样本引用数 + 训练项引用数,阶段 0 已建)。
  - > 0:提示「N 条样本 / 训练项在用,无法删除」,不删。
  - = 0:弹 `AlertDialog` 确认「删除这个错误类型?」→ 确认后删,chip 消失。
- 被引用的错误类型不可删,防误删连锁(R-014)。

### F4 删除安全现状(已落地,本阶段不重复实现)

- 样本删除:阶段 2 SampleEdit AlertDialog 确认(样本无下游,不需引用检查)。✅
- 原则删除:阶段 6 PrincipleList/Edit AlertDialog 确认(原则是末端对象,无表引用)。✅
- 训练项:阶段 5「结束」对话框(完成 / 放弃),只结束不物理删除。✅
- 领域:阶段 1 只隐藏不物理删除(hidden Switch),无删除流程。✅
- 错误类型:本阶段 F3 补齐。❌→✅

## 边界与约束

- **导出 JSON 含 meta**:版本号 + 导出时间,便于后续迁移与导入校验(导入本阶段不做,但格式预留)。
- **导入不做**:R-013 只要求导出,技术方案 §7 明确导入可选。
- **导出无需存储权限**:走 SAF `CREATE_DOCUMENT`,系统处理权限,App 不申请存储权限。
- **错误类型被引用不可删**:`referenceCount > 0` 拦截,提示具体引用数。未引用才可删。
- **领域不物理删除**:阶段 1 决策,用 hidden 停用。技术方案「删领域前迁移样本」不落地——因为不删领域。文档声明此偏离(D4)。
- **导出失败不崩**:用户取消选择器 / 写入异常,提示未完成,不报错。

## 验收标准

对齐 [MVP 需求文档](MVP需求文档.md) 验收标准 9(导出核心数据)+ R-014(删除均有确认 / 引用检查)。

1. 能从周复盘页顶部进入设置页,点「导出数据」。
2. 导出生成一个 JSON 文件,包含领域 / 样本 / 错误类型 / 训练项 / 原则五表数据 + meta。
3. 导出走系统文件保存选择器,无需手动授权存储权限。
4. 导出取消或失败时不崩,提示未完成。
5. 错误类型 chip 长按可触发删除:被引用时拦截提示引用数,未引用时确认后删除。
6. 删除操作均有确认对话框或引用检查(样本 / 原则确认,错误类型引用检查 + 确认,训练项只结束,领域只隐藏)。
