# GrowthOS 阶段 1:领域管理 需求文档

## 文档定位

本文件是二期阶段 1(领域管理)的细化需求。需求基线以 [MVP 需求文档](MVP需求文档.md) R-001 为准,本文件不重复 R-001 的措辞,只把它落地到可实施的交互、字段与边界。技术实现见配套《阶段1-领域管理-设计》。

## 范围

做:

- 创建领域(必填名称)
- 查看领域列表(chips 形式,在领域页顶部)
- 切换当前选中领域(驱动领域页内容,阶段 3 接真数据)
- 改名
- 隐藏 / 恢复(隐藏后不出现在 chips,已关联样本保留)
- 当前选中领域持久化(退出再进保持)
- 首次启动无领域的空状态引导

不做(留到后续阶段):

- 删除领域(阶段 7,需引用检查)
- 领域详情页四区块接真数据(阶段 3)
- 领域排序 / 拖拽、领域描述 / 颜色等扩展字段(MVP 外)

## 用户场景

1. **首次打开**:领域页空状态,提示"先建一个领域",点入口直接进新建对话框。
2. **建领域**:在领域页点"+ 新建",输入名称(如"编程"),保存。chips 立即出现新领域并自动选中。
3. **切换**:点另一个 chip,当前选中切换,领域页标题随之变化(统计区块阶段 3 才接数据,本阶段先切选中态)。
4. **改名**:在某领域上触发编辑动作,改名保存,chips 更新。
5. **隐藏**:暂时不用的领域(如"拳击")隐藏,chips 不再显示;已录样本不受影响。
6. **恢复**:在"已隐藏"区展开,可恢复某领域。
7. **录样本时选领域**:阶段 2 录入页从可见领域列表里选,本阶段先把可见列表与选中态备好。

## 功能点

### F1 领域列表展示

- 位置:领域页([DomainScreen](../android/app/src/main/java/com/growthos/app/ui/domain_view/DomainScreen.kt))顶部 chips 区。
- 内容:所有未隐藏领域,按创建时间升序。
- 选中态:当前选中领域高亮;默认选中第一个可见领域(或上次选中的,见 F5)。
- 替换:现 DomainScreen 写死的 `listOf("编程", "酒馆战旗", "羽毛球", "CF")` 全部替换为真数据。

### F2 新建领域

- 入口:领域页 chips 区末尾的"+ 新建"chip,或空状态引导按钮。
- 形态:底部对话框(单字段:名称)。
- 校验:名称 trim 后非空,长度上限 20 字符。
- 提交:保存后对话框关闭,新领域出现在 chips 末尾并自动选中。
- 重名:不阻断(系统允许重名),提交前若已有同名领域,软提示"已有同名领域,仍要创建?",用户可继续。详见设计 D2。

### F3 改名

- 入口:领域 chip 上的编辑动作(长按 chip,或编辑入口)。
- 形态:同 F2 对话框,预填当前名称。
- 校验:名称 trim 后非空。

### F4 隐藏 / 恢复

- 隐藏入口:领域编辑对话框内的"隐藏此领域"开关。
- 隐藏行为:chip 从列表消失;已关联该领域的样本保留,不受影响。
- 恢复入口:领域页底部"已隐藏(N)"折叠区,展开列出已隐藏领域,每项可"恢复"或"编辑"。
- 恢复行为:领域重新出现在 chips,不自动选中(保持当前选中不变)。

### F5 当前选中领域持久化

- 切换领域后,选中的领域 id 记住,下次进入领域页仍是上次选的。
- 若上次选中的领域被隐藏或不存在,回退到第一个可见领域;无可见领域则进入空状态。

### F6 空状态

- 无可见领域时:领域页 chips 区显示空状态文案("还没有领域,先建一个")+ "新建领域"主按钮。
- 隐藏最后一个领域也回到空状态。

## 字段与校验

| 字段 | 类型 | 必填 | 校验 |
|---|---|---|---|
| name | String | 是 | trim 后非空,长度 ≤ 20 |
| createdAt | Long(epoch millis) | 系统 | 自动填,不可改 |
| hidden | Boolean | 系统 | 默认 false |

## 边界与约束

- **首次启动**:阶段 0 种子只插了 8 个错误类型,没有领域。领域页首次进入是空状态,这是预期行为。
- **隐藏最后一个领域**:回到空状态。
- **删除**:本阶段不做。用户想"去掉"一个领域只能隐藏;真正删除留到阶段 7(需引用检查:删领域前要迁移 / 删其下样本)。
- **重名**:系统允许(无唯一约束),产品层软提示不阻断。
- **并发**:自用单设备,不考虑并发写。

## 验收标准

对齐 [MVP 需求文档](MVP需求文档.md) 验收标准 1:用户可以创建至少 3 个不同领域。

1. 能新建 3 个领域(如"编程""酒馆战旗""羽毛球"),chips 按创建顺序显示。
2. chips 反映真实领域,非写死占位。
3. 能改名,改名后 chips 立即更新。
4. 能隐藏一个领域,chips 不再显示;恢复后重新出现。
5. 退出 app 再进,当前选中领域保持。
6. 首次启动(无领域)看到空状态引导,能从空状态直接新建。
