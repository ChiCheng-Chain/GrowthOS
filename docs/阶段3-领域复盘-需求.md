# GrowthOS 阶段 3:领域复盘视图 需求文档

## 文档定位

本文件是二期阶段 3(领域复盘视图)的细化需求。需求基线以 [MVP 需求文档](MVP需求文档.md) R-007、R-008 为准,本文件不重复原文措辞,只把它落地到可实施的交互与边界。技术实现见配套《阶段3-领域复盘-设计》。前置依赖:阶段 0 数据层、阶段 1 领域管理、阶段 2 样本记录已落地。

阶段 3 是闭环第 5 步的领域维度——把领域页四区块从 [SampleStub](../android/app/src/main/java/com/growthos/app/domain/model/SampleStub.kt) 占位换成真实聚合数据,并补上 R-007 的样本筛选。这一阶段全是"看数据",无新录入入口(训练项录入留阶段 5,原则录入留阶段 6)。

## 范围

做:

- 领域页四区块接真聚合数据(替换占位):
  - 最近样本(该领域)
  - 错误类型分布(该领域,频次条形)
  - 当前进行中训练项(该领域)
  - 近期原则(该领域)
- 四区块随当前选中领域切换
- 样本列表按错误类型 / 归因筛选(R-007 should 级)
- 清理 [SampleStub](../android/app/src/main/java/com/growthos/app/domain/model/SampleStub.kt) 占位(领域页用到的部分;若阶段 2 后只剩此处引用,删文件)

不做(留后续):

- 新建训练项 / 原则的录入页 → 阶段 5 / 阶段 6(本阶段只读展示已有,无录入入口;阶段 0 种子未插训练项 / 原则,故本阶段这两块初始为空状态)
- 周复盘全局视图 → 阶段 4
- 训练前后效果对比页 → 阶段 5
- 跨领域全局统计 → 阶段 4(周复盘跨领域)
- 自定义时间范围筛选 → 阶段 4(周复盘时间选择器)

## 用户场景

1. **看领域全貌**:进领域页,选中"编程",看到该领域最近几条样本、错误类型分布条形、当前在练的训练项、近期沉淀的原则——一页看懂这个领域在练什么、犯什么错。
2. **切换领域**:点另一个 chip,四区块整体刷新成新领域的数据。
3. **顺错误类型追样本**:在错误分布里看到"边界条件遗漏"频次最高,点它,下方样本列表筛出所有该错误类型的样本。
4. **顺归因筛样本**:想看这个领域哪些是自己可控的,按"可控错误"筛,列表只剩可控的样本。
5. **空领域**:新领域还没录样本,四区块显示空状态引导去记录。

## 功能点

### F1 最近样本

- 位置:领域页选中领域标题下方区块。
- 数据:`SampleRepository.observeRecentByDomain(domainId, limit)`(阶段 0 已备),按 `recordedAt DESC`,limit 取最近 5 条。
- 展示:行式(时间 / 结果 / 错误类型 · 归因 / 复盘),复用 [Ledger.kt](../android/app/src/main/java/com/growthos/app/ui/components/Ledger.kt) 行样式。点击进样本编辑页(复用阶段 2 SampleEdit 路由)。
- 空状态:该领域无样本 → "还没有样本,去记录一条"。

### F2 错误类型分布

- 位置:最近样本下方。
- 数据:`SampleRepository.observeTopErrorTypes(domainId, startMillis=0, endMillis=Long.MAX_VALUE, limit)`(全时段该领域,阶段 0 已备),按频次倒序。limit 取前 8(领域页密度,避免过长)。
- 展示:复用 [DistributionBar](../android/app/src/main/java/com/growthos/app/ui/components/Ledger.kt)(墨色条 + 等宽计数),替换 `SampleStub.errorDistribution`。
- 交互:点某条 → 触发 F4 按该错误类型筛选样本列表。
- 空状态:该领域无样本 → 不显示本区块(或显示空提示)。

### F3 当前训练项

- 位置:错误分布下方。
- 数据:`TrainingRepository.observeByDomain(domainId)` 过滤 `status == IN_PROGRESS`(DAO 有 observeByDomain,Repository 可加 observeInProgressByDomain 或 UI 过滤),按 `startedAt DESC`。
- 展示:复用 [NextActionBlock](../android/app/src/main/java/com/growthos/app/ui/components/Ledger.kt)(琥珀左边框,强调"面向未来"),展示训练目标 + 关联错误类型名 + 开始时间。
- 空状态:无进行中训练项 → "还没有训练项"(阶段 5 才能新建,本阶段只读)。
- 只读:本阶段不提供新建 / 结束入口(留阶段 5)。

### F4 近期原则

- 位置:训练项下方。
- 数据:`PrincipleRepository.observeByDomain(domainId)`(阶段 0 已备),按 `createdAt DESC`,limit 取前 5。
- 展示:行式原则内容 + 创建时间。无关联对象的容错(关联字段可空)。
- 空状态:无原则 → "还没有原则"(阶段 6 才能新建,本阶段只读)。
- 只读:本阶段不提供新建 / 编辑 / 删除入口(留阶段 6)。

### F5 样本筛选(R-007 should)

- 位置:领域页底部(四区块之下),独立的"该领域样本列表"区,带筛选条。
- 数据:`SampleRepository.observeByDomain(domainId)`(阶段 0 已备),按 `recordedAt DESC`。
- 筛选:错误类型(单选,从该领域出现过的错误类型里取,含"全部")+ 归因(单选,四值 + "全部")。两者可叠加。
- 交互:点 F2 错误分布条 → 自动设错误类型筛选并滚动到样本列表。
- 展示:同 F1 行式。点击进编辑页。
- 空状态:无样本 → 同 F1 空状态;有样本但筛选无结果 → "没有符合条件的样本"。

### F6 四区块联动选中领域

- 当前选中领域变(阶段 1 chips 切换)→ 四区块 + F5 列表整体刷新。
- 选中领域为空(无可见领域)→ 领域页整体空状态(阶段 1 已处理),四区块不展示。

## 边界与约束

- **时间范围**:本阶段四区块统计用全时段(`startMillis=0, endMillis=MAX`),不做时间选择器(留阶段 4)。最近样本按条数 limit,不按时间。
- **训练项 / 原则为空**:阶段 0 未种子这两表,阶段 3 不建录入页,故这两块初始必为空状态。这是预期——空状态引导是本阶段交付物,录入入口在后续阶段。
- **跨领域统计**:本阶段所有统计绑定当前选中领域,无全局视图(留阶段 4)。
- **筛选范围**:F5 筛选只作用于该领域样本列表,不影响 F1 最近样本(最近样本始终是该领域最近 5 条)。

## 验收标准

对齐 [MVP 需求文档](MVP需求文档.md) 验收标准(本阶段对应 R-007 / R-008,验收标准表无直接编号条目,归入闭环可观察性):

1. 领域页四区块展示真实数据(非 SampleStub 占位),随选中领域切换。
2. 错误类型分布反映该领域真实频次,条形按频次排序。
3. 能按错误类型筛选该领域样本;能按归因筛选;两者可叠加。
4. 该领域无样本时四区块显示空状态引导。
5. 训练项 / 原则区块在有数据时展示,无数据时空状态(本阶段无录入入口,预期初始空)。
6. 点击最近样本 / 筛选列表项能进入样本编辑页(阶段 2 路由复用)。
